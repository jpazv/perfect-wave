Ride the session instead of chasing it. See what Claude touches, spend less per turn, and stop the commands you never meant to run.

Install in two commands, then /reload-plugins.

claude plugin marketplace add jpazv/perfect-wave
claude plugin install perfect-wave@perfect-wave --scope user
No daemon, no extra process. Works in the terminal and the desktop app.

One session, as the pane sees it.

Every line is something Perfect Wave does while you work. Open one to see the real pane.

  • 21:04:12Edit src/app.tsSEEN ●

    A file tree that follows Claude.

    • The root is the session's working directory and moves when Claude cds.
    • When Claude reads or edits a file, its folders open, the cursor jumps to it and the row glows while the tool runs.
    • Every row carries its git status: +added −removed lines and M, A, D, ??. The title shows the branch with ahead and behind.
    • Click a file to drop @path into your prompt. j k h l to move, / to filter.
  • 21:05:40prompt "translate this README"LOW ↓ SAVED

    An effort router that never breaks your cache.

    Each request is scored from the prompt: risk and architecture words weigh the most, plain text work and git chores subtract. The router changes only the effort, never the model, because a model switch re-sends the whole conversation and an effort change keeps the cache hit.

    • Plain text or chores run at low, routine code at medium, heavy or risky work at high with a short plan first.
    • Unclear prompts ask Haiku in one 5-token call with no history.
    • If a lowered turn takes more than 10 steps or hits 2 tool errors, the router stops lowering for 3 turns.
  • 21:06:02git push --force origin mainDENIED

    Guardrails that hold in auto mode.

    Checked by the engine before a tool runs. Commands are parsed by segment, so cd x && git push -f is caught and echo "git push --force" is not.

    git push --force, -f, --force-with-lease, --mirrorDENIED
    git push to main or masterASKS
    gh pr mergeASKS
    Agent, Task, WorkflowASKS
  • 21:07:18/wave hunter pdfREVIEW ◐

    Read a skill before it runs.

    • Search the public skills.sh index from the pane. Nothing is executed.
    • Review downloads only that skill's SKILL.md, and Claude flags data exfiltration, curl | sh, credential requests and scripts that run on their own.
    • Install appears only after a review, still asks for confirmation, and runs with telemetry off.
  • 21:08:30/wave skills review14 OF 101

    Every skill you have, in one place.

    • Sorted into groups by name and plugin, each a tile with its count.
    • One search across names and descriptions in every group.
    • Click a skill and /skill-name is written into your prompt, ready for arguments.
  • 21:09:55turn ended · 199.6k tokens$0.23 · CACHE 89%

    Measured, not estimated.

    A dashboard built from what the engine reports and the usage of each response. Nothing is estimated unless it says so.

    • Cost, tokens, turns, cache hit rate and context usage by category.
    • Your 5-hour and weekly limits, time to reset and burn rate.
    • What the cache saved and how many requests the router adjusted.
